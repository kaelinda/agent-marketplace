# Icon DNA — Education

Learning platforms, language apps, courses, reference tools, study aids. The category where
warmth is the differentiator, because the default is institutional and the default is wrong.

## 1. Mental model

Learning apps are used in a state of **mild aversion**. Almost nobody opens a language app
because they want to; they open it because they said they would. The icon's job is to lower
the activation energy — it should feel like an invitation, not an obligation.

This is why the institutional register (cold blue, graduation cap, serif authority) is a
mistake for most consumer learning products: it makes the app feel like homework. Duolingo's
green cartoon owl is not a failure of taste, it is a correct read of the psychology.

| Sub-register | Register |
|---|---|
| Consumer habit-forming (language, daily practice) | Warm, friendly, saturated, characterful |
| Professional / skills | Warm but restrained; competence without institution |
| Reference (dictionaries, encyclopedias) | Calm, quiet, authoritative, paper-adjacent |
| Kids | Maximum warmth, high saturation, organic forms |

## 2. Metaphors

**Exhausted:**
- Graduation cap / mortarboard
- Open book
- Apple (the fruit — and doubly confusing on Apple platforms)
- Lightbulb
- Pencil
- Blackboard / chalk
- Brain

**In use:** Duolingo = green owl · Khan Academy = green leaf-tree ·
Coursera = blue circle-monogram · Anki = blue star · Quizlet = blue-purple lightning ·
Babbel = orange speech mark · Brilliant = coloured geometric forms

**Open:**
- **Seed / sprout** — growth over time; warm; strong habit-formation fit
- **Stepping stones** — incremental progress; excellent silhouette
- **Key** — unlocking understanding; warm and physical
- **Lens focusing light to a point** — comprehension made literal without a lightbulb
- **Thread being drawn through** — connecting ideas
- **Layered strata** — accumulated knowledge; fits the layered material language
- **Bridge / arch** — crossing from not-knowing to knowing
- **Origami fold** — transformation of a simple thing into a complex one

## 3. Shape language

- **Circle** — friendly, complete, safe; the strongest default here
- **Organic blob** — warmth and play, especially for kids
- **Arc / bridge** — progress and crossing
- **Layered stack** — accumulation
- **Avoid:** the square/institutional register unless the product is genuinely enterprise
  training, and even then warm it up

## 4. Material

| Role | Recommendation |
|---|---|
| Primary | **Glazed ceramic** (warm) or **paper** (reference) |
| Accent | Wood, or a single warm glass element |
| Reflection | Subtle |
| Transparency | 0–15% |
| Edge | Soft rounded bevel — soft edges read as approachable |
| Finish | Satin |

Wood is underused and works unusually well here: it reads as crafted, patient, and
non-institutional. Consider it for reference and skills products.

## 5. Palette

**Consumer warm:**
```
Warm blue #2563EB · Amber #F59E0B · Cream #FEF3C7
```

**Growth:**
```
Sage #84A98C · Warm sand #E7E5E4 · Terracotta #C2673F
```

**Reference calm:**
```
Bone #F5F5F4 · Ink #1C1917 · one muted accent
```

**Collision map:** green owl-adjacent → Duolingo · green leaf → Khan Academy ·
institutional blue circle → Coursera and most MOOCs · blue-purple lightning → Quizlet.

Warmth is the lever. Cold blue is the category default and it is what makes education apps
feel like obligations.

## 6. Traps

| Trap | Why it fails |
|---|---|
| Graduation cap | The single most exhausted glyph in the category |
| Open book | Second most; also illegible at 40px |
| An apple | Confusing on Apple platforms, and a US-specific cultural reference |
| Lightbulb | Means "idea" generically; conveys nothing about learning |
| Institutional cold blue | Makes the app feel like homework |
| Serif authority styling | Reads as a textbook publisher, not a habit |
| A cartoon mascot invented for the icon | Mascots need personality across many surfaces to earn their place; one in an icon alone reads as thin |

## 7. Prompt fragments

**Warm ceramic:**
```
a smooth glazed ceramic form in warm cream with a single amber inner element,
soft subsurface scattering, gentle broad specular from a large light above,
satin glaze, warm and inviting, soft rounded edges, cream field
```

**Wood + brass:**
```
a smooth finished hardwood form with one thin brushed-brass inlay,
fine subtle grain, satin oil finish, warm tone,
single soft key light from above, short soft contact shadow, patient and crafted
```

**Sprout / growth:**
```
a single simple sprouting form emerging from a smooth ceramic base,
two clean leaves only, no botanical detail, soft matte glaze,
warm sage and cream palette, extremely simplified silhouette
```

**Category negatives:**
```
graduation cap, mortarboard, diploma, scroll, open book, books, bookshelf, apple, lightbulb,
pencil, pen, ruler, blackboard, chalkboard, chalk, abacus, brain, owl, backpack, school,
classroom, serif text
```
