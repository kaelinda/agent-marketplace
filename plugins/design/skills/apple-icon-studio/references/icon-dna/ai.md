# Icon DNA — AI

The most crowded and most homogeneous category in the store. Almost every icon shipped since
2023 converged on the same three moves, which means the differentiation opportunity is
unusually large for anyone willing to leave the consensus.

## 1. Mental model

Users approach an AI app expecting **capability without comprehension**. They do not know how
it works and do not want to; they want to know what it will do *for them*. The icon's job is
to promise a relationship — assistant, collaborator, oracle, tool — not to depict a technology.

The relationship framing is the fork:

| Framing | Implies | Icon register |
|---|---|---|
| Assistant | It helps you do your work | Warm, approachable, secondary |
| Collaborator | It works alongside you | Balanced, dual forms, symmetry |
| Oracle | It knows things you don't | Singular, luminous, centred, still |
| Tool | It executes precisely | Cool, engineered, geometric |
| Agent | It acts on your behalf | Directional, layered, in-motion |

Decide this at layer 1. It determines more than any other single choice in the category.

## 2. Metaphors

**Exhausted — kill on sight unless exceptionally justified:**

- Sparkle / sparkle cluster (universal "has AI" marker since 2023; now conveys nothing)
- Brain, neural mesh, node graph
- Chat bubble
- Glowing orb / gradient sphere
- Robot, android head
- Infinity loop
- Concentric "signal" rings (AirDrop already owns this shape at the system level)

**In use by leaders — collision risk:**

| Product | Mark |
|---|---|
| OpenAI | Interlocking knot / flower, monochrome |
| Anthropic | Radiating asterisk-burst, clay/terracotta |
| Gemini | Four-pointed star, blue→violet gradient |
| Perplexity | Nested angular brackets, teal |
| Copilot | Ribbon loop, blue→pink gradient |
| Midjourney | Sailboat |
| Cursor | Angular cursor form, near-black |

**Open — genuinely under-used:**

- **Lens / aperture** — synthesis and focus; strong physical affordance for material
- **Prism** — one input, many outputs; refraction is the current house material, so it renders
  natively
- **Tuning fork / resonance** — alignment and response; unusual and legible
- **Seed / germ** — generative without being a sparkle
- **Loom / weave** — synthesis from many threads; excellent negative-space potential
- **Key / keyhole** — unlocking capability; warm, human, non-technical
- **Compass rose, but asymmetric** — direction without Safari collision
- **Thread pulled from a knot** — untangling; the strongest "makes complexity simple" metaphor
  available

**Best open direction:** anything that renders as a *physical object with optical behaviour*.
The category's default is a glowing abstraction, so a real object with a real surface is
immediately differentiating.

## 3. Shape language

- **Circle / sphere** — the category default. Avoid unless doing something structural with it.
- **Prism / faceted form** — reads as transformation; refracts well; open.
- **Nested forms** — good for "layers of understanding"; concentric radii matter.
- **Asymmetric radial** — a radial form with one deliberate break reads as intelligent rather
  than decorative, and breaks the symmetry that makes every AI icon look alike.
- **Avoid:** four-pointed stars (Gemini), radiating bursts (Anthropic), knots (OpenAI).

## 4. Material

| Role | Recommendation |
|---|---|
| Primary | **Liquid glass** (native, but crowded) or **glazed ceramic** (differentiating) |
| Accent | Anodised metal, or a single luminous core |
| Reflection | Medium |
| Transparency | 20–35% |
| Edge | Soft chamfer |
| Finish | Semi-gloss |

**The ceramic move:** the entire category renders in cold glass. A warm ceramic body with a
single glass core reads as considered and human rather than technical, and it is currently
close to unoccupied. Strongly consider it if the framing is Assistant or Collaborator.

## 5. Palette

**Default (crowded):**
```
Indigo #4F46E5 · Violet #7C3AED · Near-black #0A0A0F · Glass white #F8FAFC
```

**Differentiating alternatives:**
```
Warm:      Amber #F59E0B · Terracotta #C2673F · Cream #FEF3C7
Monochrome: Graphite #18181B · Warm white #FAFAF9 · one small accent
Deep green: Forest #14532D · Sage #84CC16 · Bone #F5F5F4
```

**Collision map:** near-black+white → OpenAI · clay/terracotta → Anthropic ·
blue-violet gradient → Gemini · teal → Perplexity · blue-pink gradient → Copilot.

Note that terracotta is now Anthropic's — the "warm" move needs to land on amber or clay-red
rather than Anthropic's specific clay.

## 6. Traps

| Trap | Why it fails |
|---|---|
| Adding a sparkle "so people know it's AI" | Universally applied, so it signals follower |
| Purple-blue gradient by default | Indistinguishable from four market leaders at 40px |
| Depicting the model | Nobody has a mental image of a model; you will land on a brain |
| Glow doing all the work | Glow disappears in tinted mode; the icon becomes a grey blob |
| Over-abstraction | A gradient sphere is not a metaphor, it is a shrug |
| Chat bubble | Depicts the UI, not the meaning — and it is a messaging-app shape |
| Trend-locked iridescence | Reads as "generated in 2026" within two years |

## 7. Prompt fragments

**Ceramic + glass core (differentiating):**
```
glazed warm-white ceramic body with a single liquid-glass core suspended inside,
subsurface scattering through the ceramic, deep internal refraction in the core,
soft broad specular along the top edge, semi-gloss glaze
```

**Prism / refraction (native to current Apple language):**
```
a clean geometric prism in polished optical glass, true refraction bending the field behind it,
subtle chromatic dispersion at the edges, single soft key light from above,
no visible environment reflection
```

**Warm monochrome (restraint move):**
```
a single matte graphite form with one thin brushed-brass edge highlight,
warm off-white field, no gradient on the subject, extremely restrained,
soft short contact shadow
```

**Category negatives — always add:**
```
brain, neural network, node graph, chat bubble, sparkle, sparkles, stars, robot, android,
glowing orb, infinity symbol, circuit board, binary, matrix, hologram, iridescent chrome
```
