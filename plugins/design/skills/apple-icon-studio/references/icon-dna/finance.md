# Icon DNA — Finance

Banking, investing, payments, accounting, crypto. The category where the icon's primary job is
not differentiation but **trust**, and where a design mistake carries a real conversion cost.

## 1. Mental model

A finance icon is asking the user to believe their money is safe. Everything about the design
either supports or undermines that.

Trust reads as: **stability, symmetry, restraint, precision, and material weight.** It does
not read as playfulness, asymmetry, high saturation, or novelty.

This constrains the space more than any other category, which is why finance icons converge —
and why the ones that break out (Cash App, Robinhood, Monzo) do so by adopting a *consumer*
register deliberately, accepting a trust cost in exchange for approachability. That is a
legitimate strategy but it must be a decision, not an accident.

| Positioning | Register |
|---|---|
| Institution / wealth | Deep navy, symmetry, metal, near-monochrome |
| Consumer / neobank | One saturated hue, simple geometry, high approachability |
| Trading / active | Dark chrome, precision, instrument-like |
| Crypto | Currently reads as either institution or casino — pick deliberately |

## 2. Metaphors

**Exhausted:**
- Upward arrow / rising line
- Dollar sign, currency symbols
- Bar chart, candlestick chart
- Coin, coin stack
- Piggy bank
- Shield with a lock (the security cliché, not a finance metaphor)
- Wallet

**In use:** Stripe = indigo, monogram-ish · Robinhood = green feather ·
Cash App = green dollar-square · Revolut = black R · Monzo = coral gradient ·
PayPal = blue double-P · Wise = green flag-form · Coinbase = blue circle

**Open:**
- **Balance / scale point** — equilibrium without a literal scale
- **Vault door geometry** — concentric mechanical precision; strong material affordance
- **Ledger fold** — the record, physically
- **Seal / stamp** — verification, authority; excellent at small sizes
- **Keystone** — the piece that holds the structure
- **Horizon / rising ground plane** — growth without an arrow
- **Tessellation** — accumulation and structure
- **Ingot / bar with a chamfer** — value made physical; renders beautifully in metal

## 3. Shape language

- **Rounded rectangle** — stability, records, institution; the honest default
- **Circle** — completeness, safety, consumer approachability
- **Shield-arc** — protection (careful: heavily used in security software)
- **Hexagon** — reads as crypto/blockchain in this category specifically
- **Symmetry is close to mandatory** on the institutional side. Asymmetry reads as instability,
  which is exactly the wrong signal.

## 4. Material

| Role | Recommendation |
|---|---|
| Primary | **Brushed metal** (institution) or **glazed ceramic** (consumer) |
| Accent | Crystal, or a single polished metal edge |
| Reflection | Subtle to medium |
| Transparency | 0–10% — opacity itself reads as solidity |
| Edge | Machined chamfer |
| Finish | Satin |

Metal carries weight and weight carries trust. This is the one category where a slightly
heavier, more solid material read is strictly better.

## 5. Palette

**Institution:**
```
Navy #1E3A8A · Silver #CBD5E1 · Deep slate #0F172A
```

**Growth / consumer:**
```
Emerald #059669 · Bone #F5F5F4 · Graphite #1F2937
```

**Premium:**
```
Near-black #0A0A0A · Brass #B08D57 · Bone #F5F5F4
```

**Hard rule: red is loss.** Never a dominant hue in finance. A red finance icon triggers the
wrong association instantly, regardless of intent.

**Collision map:** indigo → Stripe · green feather → Robinhood · green dollar-square → Cash
App · black minimal → Revolut · coral gradient → Monzo · blue circle → Coinbase.

## 6. Traps

| Trap | Why it fails |
|---|---|
| Upward arrow | Every finance app since 2010 |
| Dollar sign | Currency-specific, so it fails internationally, and it is a text glyph |
| Bar or candlestick chart | Depicts the UI; illegible at 40px |
| Red as dominant | Reads as loss |
| Playful asymmetry on an institutional product | Undermines trust |
| Gold gradient "premium" | Reads as a scam; brass as a *material* works, gold gradient does not |
| Shield + lock | Security software cliché, not a finance metaphor |
| Crypto hexagon | Instantly categorises the product whether you want it or not |

## 7. Prompt fragments

**Institutional metal:**
```
a solid machined form in brushed navy-anodised metal with one polished silver chamfer,
fine anisotropic grain, single soft key light from directly above,
perfectly symmetrical, deep slate field, weighty and precise
```

**Consumer ceramic:**
```
a smooth glazed ceramic form in warm bone white with a single emerald inner element,
soft subsurface scattering, gentle broad specular, satin glaze,
approachable and calm, soft short contact shadow
```

**Premium brass:**
```
a chamfered ingot form in warm brushed brass on a near-black field,
satin metal finish, one thin bright edge highlight along the top chamfer,
extremely restrained, no gradient on the subject
```

**Category negatives:**
```
dollar sign, currency symbol, euro, yen, upward arrow, arrow up, bar chart, candlestick,
line graph, coin, coins, piggy bank, wallet, credit card, bank building, columns, pillars,
shield, padlock, gold gradient, red
```
