# Icon DNA Library

Ten category files, each pre-digesting what a run in that category would otherwise have to
rediscover: the users' mental model, the metaphors Apple and the market already use, the shape
and material and palette that fit, the traps, and reusable prompt fragments.

Read the relevant file at **layer 1**, as soon as the category is known — before generating
metaphors. Layer 2 should start from the state of the art, not from zero.

## Files

| File | Covers |
|---|---|
| `ai.md` | AI assistants, LLM tools, agents, copilots |
| `productivity.md` | Tasks, notes, calendars, PM tools |
| `developer.md` | Editors, CLIs, terminals, dev infrastructure |
| `media.md` | Music, video, photo, podcast, creative tools |
| `finance.md` | Banking, investing, payments, accounting |
| `education.md` | Learning, courses, language, reference |
| `health.md` | Fitness, meditation, medical, sleep |
| `social.md` | Messaging, communities, feeds, forums |
| `utilities.md` | System tools, converters, launchers, small tools |
| `games.md` | Games and game-adjacent tools |

## Structure

Every file follows the same seven sections:

1. **Mental model** — what users already believe about this category
2. **Metaphors** — what is used, what is exhausted, what is open
3. **Shape language** — which forms fit and why
4. **Material** — primary/accent recommendations
5. **Palette** — with competitive-collision notes
6. **Traps** — the specific ways icons in this category fail
7. **Prompt fragments** — drop-in text for layer 8

## Maintaining it

This library is the compounding asset. After a run, write back anything durable you learned:
a metaphor that turned out to be exhausted, a competitor whose palette shifted, a material
that rendered badly in this category.

Keep it to **durable category facts**. A specific product's decisions belong in
`examples/`, not here.
