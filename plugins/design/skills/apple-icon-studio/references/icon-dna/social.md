# Icon DNA — Social & Communication

Messaging, communities, feeds, forums, dating, collaboration. The hardest category for
differentiation, because the metaphor space is small, exhausted, and defended by icons with
enormous brand equity.

## 1. Mental model

Social icons are tapped more often than any other and are recognised **pre-attentively** — the
user's thumb is already moving before the icon is consciously read. That places extreme weight
on colour and silhouette and almost none on detail.

It also means the icons users already know are effectively immovable landmarks. A new social
app is not competing for taste, it is competing for a slot in a spatial memory that is already
full.

The strategic implication: **win on shape, not on colour.** Every colour worth having is taken
(green → WhatsApp, blue → Messenger/Telegram/Twitter-era, blurple → Discord, gradient →
Instagram, black → X, multi-hue → Slack). Shape is the remaining open dimension.

| Sub-register | Register |
|---|---|
| Private messaging | Calm, trustworthy, intimate, quiet |
| Public feed | Bold, high-contrast, energetic |
| Community / forum | Warm, plural, gathering |
| Professional | Restrained, credible, structured |
| Dating | Warm, emotional, but not literal |

## 2. Metaphors

**Exhausted:**
- Speech bubble (owned collectively by the entire category)
- Two overlapping human silhouettes
- Paper plane (Telegram)
- Envelope
- @ symbol
- Heart (dating)
- Globe / network mesh

**In use:** WhatsApp = green speech bubble + phone · Telegram = blue paper plane ·
Discord = blurple game-controller-face · Slack = multi-hue octothorpe · X = black monogram ·
Instagram = gradient camera outline · Signal = blue speech bubble · Reddit = orange alien ·
Messenger = blue-purple gradient bubble

**Open:**
- **Two forms in overlap / interference** — connection without human figures
- **Ripple / concentric response** — a message landing (careful: AirDrop-adjacent)
- **Knot / weave** — many-to-many community; excellent negative space
- **Table / gathering surface** — community as a place rather than a network
- **Tuning forks in resonance** — being heard; unusual and warm
- **Threaded line** — conversation as continuity
- **Nested enclosure** — privacy, a room within a room
- **Bridge** — connection across distance

## 3. Shape language

- **Circle** — friendly, human, safe; the private-messaging default
- **Two-form overlap** — connection made structural rather than depicted
- **Organic blob** — warmth, community, play
- **Rounded rectangle** — reads as professional/structured (LinkedIn register)
- **Avoid:** the speech-bubble outline in every variant. It is not just crowded, it is the
  category's generic mark.

## 4. Material

| Role | Recommendation |
|---|---|
| Primary | **Glazed ceramic** or **soft fabric** — warm, human, tactile |
| Accent | Liquid glass |
| Reflection | Subtle to medium |
| Transparency | 10–25% |
| Edge | Soft rounded |
| Finish | Satin |

Fabric is nearly unused in this category and reads as genuinely human in a way that glass does
not. Worth serious consideration for community products.

## 5. Palette

Every strong hue is claimed. The realistic options:

**Warm (relatively open):**
```
Coral #FB7185 · Warm purple #A855F7 · Cream #FFF7ED
```

**Earth (open):**
```
Terracotta #C2673F · Sand #E7E5E4 · Deep umber #44403C
```

**Restrained (professional):**
```
Deep slate #0F172A · Bone #F5F5F4 · one muted accent
```

**Collision map — effectively all taken:** green → WhatsApp · blue → Telegram/Signal/Messenger
· blurple → Discord · multi-hue → Slack · black monogram → X · warm gradient → Instagram ·
orange → Reddit · red → Pinterest/YouTube.

Given the colour space is closed, put the differentiation budget into shape and material.

## 6. Traps

| Trap | Why it fails |
|---|---|
| A speech bubble | The category's generic mark; conveys "messaging", nothing more |
| Two human silhouettes | Clip-art register; also excludes and fails at 40px |
| A paper plane | Telegram |
| Trying to win on colour | The colour space is fully occupied |
| A globe or network mesh | 2005 register; also unreadable small |
| A heart on a dating app | Literal, exhausted, and emotionally flat |
| Multi-hue "diversity" palette | Slack owns it; also no hierarchy |

## 7. Prompt fragments

**Warm ceramic overlap:**
```
two smooth glazed ceramic forms overlapping at their edges, the overlap region catching a
warmer inner light, soft subsurface scattering, gentle broad specular from above,
satin glaze, coral and cream palette, soft rounded edges
```

**Fabric weave:**
```
a single tight woven textile form with a soft fibre sheen, gentle matte weave micro-texture,
one clean interlock at the centre, warm terracotta and sand palette,
soft diffuse light from above, no specular, deeply human
```

**Resonance:**
```
two identical slender forms standing in parallel, one visibly vibrating with a soft
concentric disturbance around it, matte ceramic bodies, single soft key light,
extremely simple silhouette, warm neutral field
```

**Category negatives:**
```
speech bubble, chat bubble, message bubble, paper plane, envelope, mail, at symbol,
human silhouette, people, faces, crowd, globe, world map, network mesh, nodes, connections,
heart, thumbs up, like button, notification badge
```
