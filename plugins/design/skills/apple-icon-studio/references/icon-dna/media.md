# Icon DNA — Media & Creative

Music, video, photo, podcast, editing, streaming. The one category where colour maximalism and
high energy are licensed — and where the metaphor space is most thoroughly exhausted.

## 1. Mental model

Media apps sell **anticipation**. The icon is tapped in a moment of wanting something —
entertainment, expression, escape — and it should feel like the beginning of that rather than
like a tool.

Two sub-registers:

| Register | Products | Icon character |
|---|---|---|
| Consumption | Streaming, listening, watching | Saturated, warm, emotional, inviting |
| Creation | Editors, DAWs, colour tools | Precise, dark, instrument-like, professional |

These pull in opposite directions and mixing them produces an icon that reads as an amateur
editor. Decide which one at layer 1.

Creation-side media tools are, materially, closer to `developer.md` than to consumption-side
media — a colour grading app should look like an instrument, not like a streaming service.

## 2. Metaphors

**Exhausted:**
- Play triangle (utterly saturated; also a system-level glyph)
- Film strip, clapperboard
- Waveform
- Musical note
- Camera / camera shutter (though the *aperture* remains workable)
- Vinyl record
- Microphone (podcasts)

**In use:** Spotify = green radiating arcs · Apple Music = pink-red note ·
YouTube = red rounded play · Netflix = red N · Final Cut = blue-purple slate ·
Photoshop = blue Ps monogram · Lightroom = blue Lr · Figma = coloured shapes ·
Procreate = colour swirl · Overcast = orange arc

**Open:**
- **Aperture / iris** — one of the few surviving photo metaphors; excellent negative space
- **Prism splitting light** — colour work, grading; renders natively in the current material
  language
- **Resonating body** — a chamber, a bell, a drum shell; audio without a note or a waveform
- **Reel of thread / spool** — sequence, timeline, without a film strip
- **Cut / clean split** — editing as removal, not as a timeline UI
- **Layered translucent sheets** — compositing; strong material affordance
- **Beam through an opening** — projection, broadcast
- **Sound as physical displacement** — a surface deformed by a wave rather than a drawn wave

## 3. Shape language

- **Circle / ring** — cycles, playback, resonance; the consumption default
- **Arc** — radiating, broadcast, progress (Spotify and Overcast both live here)
- **Triangle** — direction and energy, but reads as "play" whether you want it to or not
- **Layered stack** — compositing and editing
- **Organic radial** — colour, creativity (Photos' pinwheel, Procreate's swirl)
- **Avoid:** rectangles with rounded corners containing a triangle. That is a play button.

## 4. Material

**Consumption side:**

| Role | Recommendation |
|---|---|
| Primary | Cast resin or liquid glass — deep, saturated, glossy |
| Accent | Polished metal |
| Reflection | Medium to strong |
| Transparency | 20–40% |
| Edge | Rounded bevel |
| Finish | Gloss |

**Creation side:**

| Role | Recommendation |
|---|---|
| Primary | Matte anodised metal or dark ceramic |
| Accent | One glass or luminous element |
| Reflection | Subtle |
| Transparency | 0–15% |
| Edge | Machined chamfer |
| Finish | Satin |

## 5. Palette

**Consumption:**
```
Orange #F97316 · Pink #EC4899 · Deep black #0A0A0A
```
Saturation up to ~90% is acceptable here and nowhere else.

**Creation:**
```
Near-black #101014 · one saturated accent · silver #CBD5E1
```
Dark chrome is the professional convention — the icon should look like it belongs beside a
timeline in a dark editor.

**Collision map:** green radiating arcs → Spotify · red rounded rect → YouTube ·
pink-red gradient note → Apple Music · red monogram → Netflix · orange arc → Overcast ·
blue monograms → Adobe.

## 6. Traps

| Trap | Why it fails |
|---|---|
| A play triangle | The most saturated glyph in the entire store |
| A waveform | Illegible below 80px; also every audio app |
| A musical note | Generic to the point of being a placeholder |
| Mixing consumption warmth with creation precision | Reads as an amateur editor |
| Full-spectrum rainbow ("it's creative!") | No hierarchy, unusable in tinted mode |
| Depicting the timeline UI | Dates with the UI, meaningless small |
| Neon glow on black | High store impact, glares in dark mode, ages badly |

## 7. Prompt fragments

**Consumption resin:**
```
a deep glossy cast-resin form in saturated orange, thick optical depth with a suspended
element visible inside, high-gloss domed surface, single large soft light from above,
rich specular, deep near-black field, warm and inviting
```

**Creation instrument:**
```
a matte dark-anodised chamber form with one thin luminous edge, satin metal finish,
minimal reflection, single directional key light from above, deep near-black field,
professional, precise, instrument-like
```

**Aperture:**
```
a clean geometric iris aperture with overlapping blades in brushed metal,
the opening revealing a warm luminous core, precise concentric geometry,
soft key light from above, subtle contact shadow
```

**Category negatives:**
```
play button, play triangle, film strip, clapperboard, waveform, musical note, treble clef,
vinyl record, microphone, camera, headphones, speaker, equalizer bars, timeline, rainbow,
neon glow
```
