# Icon DNA — Games

Games and game-adjacent tools. The only category where colour maximalism, character, and
outright drama are correct — and the only one where the icon is a direct conversion lever in a
store listing rather than a home-screen resident.

## 1. Mental model

A game icon has two jobs and they conflict:

1. **Convert in the store.** Seen in a scrolling grid of competitors, at ~120px, next to
   screenshots. Needs impact, saturation, and immediate genre-legibility.
2. **Live on the home screen.** Seen 40 times a day at 40px alongside a bank app and a calendar.
   Needs not to be exhausting.

Most game icons optimise entirely for (1) and lose users to (2). The resolution is usually:
**high value contrast, controlled saturation, one subject.** Drama through contrast and
composition rather than through cramming.

The icon must also communicate **genre in under 200ms**, because that is the filter users
apply before reading anything. Genre is communicated by palette and material far more than by
subject.

| Genre | Palette signal | Material signal |
|---|---|---|
| Casual / puzzle | Bright, high saturation, warm | Glossy resin, candy-like |
| Strategy | Deep, restrained, cool | Metal, stone, parchment |
| Action / shooter | High contrast, dark + one hot accent | Metal, carbon, scratched |
| RPG / fantasy | Rich jewel tones, gold | Metal, gem, leather |
| Horror | Near-monochrome, one blood accent | Rough, matte, organic |
| Sim / builder | Warm, bright, clean | Ceramic, plastic, toy-like |
| Retro / indie | Limited palette, flat | Pixel, paper, print |

## 2. Metaphors

**Exhausted:**
- Game controller / joystick / D-pad
- Sword, sword-and-shield
- Crown
- Dice
- Character face in three-quarter view (the mobile-game default; extremely crowded)
- Explosion / fire

**Open:**
- **The single hero object** — the one item the game is actually about, rendered as a museum
  piece. Consistently outperforms a character face.
- **A single dramatic material moment** — cracked stone, molten metal, frozen glass
- **Emblem / sigil** — faction marks; excellent silhouettes, strong at 40px
- **Negative-space form** — highest craft signal in a category where craft is rare
- **A single glyph from the game's own world** — the strongest brand metaphor available
- **Two-state tension** — a form caught at the moment of breaking or transforming

**On character faces:** the mobile free-to-play convention is a shouting character at
three-quarter view. It works in the sense that it is legible and emotional, but it is so
uniformly applied that it now reads as a genre marker for free-to-play rather than as
differentiation. A premium or indie game usually does better with an object or an emblem.

## 3. Shape language

- **Emblem / shield** — faction identity; strong closed silhouette
- **Single object, centred** — the museum-piece framing
- **Diamond / crystal** — value, magic, precision
- **Organic dramatic form** — creatures, energy, chaos
- **Avoid:** the controller silhouette; also avoid text in any form (game logos in icons are
  the most common violation of the no-text rule and they are unreadable at 40px)

## 4. Material

| Role | Recommendation |
|---|---|
| Primary | **Cast resin** (casual), **metal or stone** (strategy/action), **crystal** (fantasy) |
| Accent | One luminous element — the "power" cue |
| Reflection | Medium to strong — this is the one category where drama is licensed |
| Transparency | 0–40%, genre-dependent |
| Edge | Rounded bevel (casual) or hard chamfer (action) |
| Finish | Gloss (casual) to matte (horror/strategy) |

The rule of two materials still applies, and it is broken more often here than anywhere else.
Three materials plus a glow plus a particle effect is the standard mobile-game icon, and it is
mud at 40px.

## 5. Palette

**Casual:**
```
Saturated primary (#F97316 / #FBBF24) · complementary accent (#3B82F6) · deep near-black
```

**Strategy / action:**
```
Deep near-black #0A0A0A · one hot accent (#EF4444 / #F59E0B) · steel #94A3B8
```

**Fantasy:**
```
Deep violet #4C1D95 · gold #D4A24C · bone #F5F5F4
```

**Horror:**
```
Near-monochrome #18181B / #A8A29E · one desaturated blood accent #7F1D1D
```

Saturation up to ~90% is acceptable in casual. Everywhere else, hold it under 80% and get
impact from value contrast instead — an icon that is loud in *value* stays legible at 40px, one
that is loud in *saturation* does not.

## 6. Traps

| Trap | Why it fails |
|---|---|
| A game controller | Says "a game", which the store already said |
| The game's logo/wordmark in the icon | Text rule violation; unreadable at 40px |
| Character face at three-quarter view | Legible but reads as generic free-to-play |
| Three-plus materials with glow and particles | Mud at 40px; the standard mobile-game failure |
| Maximum saturation everywhere | Exhausting on a home screen; users delete for this |
| An explosion | Conveys energy, no genre, no identity |
| Optimising only for the store grid | Wins the install, loses the retention |

## 7. Prompt fragments

**Hero object (museum framing):**
```
a single hero object presented as a museum piece, centred, dramatically lit from above,
rich material detail, deep near-black field with a soft radial falloff behind it,
one luminous accent element, strong value contrast, extremely clean composition
```

**Emblem / sigil:**
```
a single carved emblem in weathered stone with one inlaid glowing element,
matte rough surface with fine erosion detail, sharp geometric silhouette,
single hard key light from above creating deep relief shadow, near-monochrome with one hot accent
```

**Casual resin:**
```
a rounded glossy cast-resin form in saturated warm orange with a suspended element inside,
thick optical depth, high-gloss domed surface, strong bright specular from above,
deep near-black field, playful and appetising, extremely simple silhouette
```

**Category negatives:**
```
game controller, joystick, gamepad, D-pad, sword, shield, crown, dice, explosion, fire,
particles, sparks, lens flare, character face, cartoon character, game logo, wordmark, text,
title, glow everywhere, rainbow, cluttered, busy
```
